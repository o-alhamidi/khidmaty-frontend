# Khidmaty

منصة عربية لربط العملاء بمزودي الخدمات المحليين، مع التسجيل، تصفح المزودين، عرض الملفات، الحجز، لوحة العميل، ولوحة الإدارة.

## المتطلبات

يحتاج المشروع إلى Node.js 20 أو أحدث، وpnpm، وقاعدة PostgreSQL متاحة. يستخدم Prisma للوصول إلى قاعدة البيانات وJWT لجلسات المصادقة.

## التشغيل المحلي

انسخ ملف البيئة النموذجي ثم حدّث القيم:

```bash
cp .env.example .env
pnpm install
pnpm exec prisma generate
pnpm dev
```

افتح `http://localhost:3000` بعد تشغيل الخادم.

## قاعدة البيانات

قبل أول تشغيل فعلي، تأكد من ضبط `DATABASE_URL` و`DIRECT_URL` في `.env`. لتطبيق تغييرات المخطط في بيئة التطوير استخدم:

```bash
pnpm exec prisma migrate dev --name init
```

لإضافة بيانات العرض التجريبية، استخدم:

```bash
pnpm exec tsx scripts/seed.ts
```

لا ترفع ملفات `.env` أو كلمات المرور أو مفاتيح JWT إلى GitHub.

## الفحص قبل التسليم

```bash
pnpm exec prisma format
pnpm exec prisma generate
pnpm exec tsc --noEmit
pnpm run build
```

## الوظائف الحالية

يحتوي المشروع على تدفقات المصادقة والتسجيل، عرض مزودي الخدمة من قاعدة البيانات، صفحات الملفات الشخصية، إنشاء الحجوزات والتحقق من جلسة العميل، إحصاءات لوحة العميل، وحماية واجهة الإدارة والعمليات الحساسة على الخادم.

قبل الإطلاق التجاري، يجب إضافة بوابة دفع، تخزين صور خارجي، إشعارات بريدية أو فورية، سياسة خصوصية وشروط استخدام، ومراقبة الأخطاء. كما يجب تشغيل migrations على قاعدة الإنتاج بعد أخذ نسخة احتياطية من قاعدة البيانات.
